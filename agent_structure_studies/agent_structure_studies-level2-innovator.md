# Agentblazer Innovator (Level 2) — Detailed Breakdown

## Overview

- **Status:** Innovator 2026
- **Difficulty:** Intermediate
- **Role:** Administrator
- **Estimated Time:** ~12 hours 20 minutes
- **Points:** +10,300
- **Prerequisite:** Agentblazer Champion (Level 1)
- **Goal:** Implement Agentforce solutions to drive measurable business outcomes.

## What You'll Learn

An Innovator can develop agent strategy, conceive new use cases, and effectively plan projects. They're capable of deploying Agentforce solutions to generate business outcomes and value in response to practical challenges. Innovators possess a strong grasp of best practices for optimizing agents, both at launch and ongoing.

## Trail Modules

| Module | Description |
|--------|-------------|
| Drive AI Within Your Organization | Develop AI strategy and identify where agents can make the biggest impact |
| Get Hands On With Prompt Builder | Hands-on experience creating and refining prompts for agent behavior |
| Customize Agentforce and Deploy Your Agents | Configure and deploy custom agents using Salesforce's Agent Builder |
| Sell Smarter with Agentforce | Configure Agentforce for Sales — help reps nurture leads and close deals |
| Close Cases Faster with Service Assistant | Configure Agentforce for Service — drive faster case resolution |
| Discover Agentforce for Industries | Explore industry-specific Agentforce solutions and use cases |

## Key Skills Developed

- **AI Strategy & Planning:** Identify business use cases where agents deliver the most value
- **Agent Builder Proficiency:** Build custom agents using Salesforce's Agent Builder tool
- **Sales Configuration:** Set up Agentforce to support sales workflows
- **Service Configuration:** Deploy Agentforce for customer service scenarios
- **Industry Solutions:** Understand how Agentforce applies across different industries
- **Optimization:** Best practices for tuning agents at launch and over time

## Key Takeaways

- This level shifts from "understanding" to "implementing"
- You go from building a basic agent to deploying real solutions for Sales and Service
- Strategic thinking is emphasized — not just how to build, but where and why
- Industry-specific use cases broaden your perspective
- Completing this unlocks Level 3 (Legend)
