# Agentblazer Champion (Level 1) — Detailed Breakdown

> Source: [Become an Agentblazer Champion 2026](https://trailhead.salesforce.com/content/learn/trails/become-an-agentblazer-champion)
> Content was rephrased for compliance with licensing restrictions.

## Overview

- **Status:** Champion 2026
- **Difficulty:** Foundational
- **Role:** End User
- **Estimated Time:** ~7 hours 13 minutes
- **Points:** +6,300
- **Goal:** Confidently explain Agentforce concepts and business impact, plus hands-on experience building a basic agent.

## What You'll Learn

A Champion can understand foundational AI and Agentforce concepts along with their business value, and has basic hands-on experience building an agent.

## Trail Modules

### Section 1: AI Foundations

| Module | Description |
|--------|-------------|
| Agentblazer Status Overview | Learn why it's important to earn Agentblazer Status and how to do it |

| Natural Language Processing | Learn how AI enables computers to interpret and generate natural human language |
| Large Language Models (LLMs) | Learn about LLMs and how Salesforce uses them |
| Responsible AI | Build trust between humans and agents with responsible AI principles that guide design, development, and use of AI |

### Section 2: Data + AI + CRM

## Key Takeaways

- This is the entry point — no prerequisites
- Covers AI basics, generative AI, NLP, LLMs, responsible AI, Data Cloud, and prompt engineering
- Hands-on: you actually build a service agent and an employee agent
- Completing this unlocks Level 2 (Innovator)
